BUILD THE PATTERN

The answer is in the order.

Study the finished pattern and build the operations it needs. Even the same moves produce a different result when their order changes.

Read the transformation between the START and GOAL four-by-four grids.

02

Arrange

Place rotations, flips, moves, and coloring operations in the correct order.

03

Check

Run your sequence. Match the GOAL pattern to clear the puzzle.
