# Security Policy

## Reporting a vulnerability

セキュリティ上の問題を発見した場合は、公開のIssueには詳細を書かず、`kamkammath2026@gmail.com` へご連絡ください。

Please do not disclose vulnerability details in a public issue. Report them privately to `kamkammath2026@gmail.com`.

報告には、影響を受けるURL、再現手順、想定される影響を含めてください。パスワード、アクセストークン、個人情報などの機密情報は送信しないでください。

Please include the affected URL, reproduction steps, and potential impact. Do not send passwords, access tokens, personal information, or other secrets.
